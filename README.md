# 5分足アーカイブ (jpx-5min-archive)

非TOPIX・時価総額350億円超の211銘柄について、株探の5分足を毎営業日蓄積している。

**📊 閲覧用サイト: https://al00000000.github.io/jpx-5min-archive/**
(銘柄検索・表示日数切替つきのローソク足+出来高チャート。
[売買代金ランキング/その他](https://al00000000.github.io/kabutan-ranking/) の「5分足」タブからも開ける)

## 構成

- `symbols.csv` … 対象銘柄リスト(コード,銘柄名,市場,株価,時価総額)。銘柄を増減したい場合はこれを編集する
- `fetch_5min.py` … 取得スクリプト(Python標準ライブラリのみ)
- `docs/data/YYYY-MM-DD.json.gz` … その日の全銘柄の5分足
- `docs/data/manifest.json` … 保存済み日付一覧と銘柄マスタ
- `docs/index.html` … 閲覧サイト
- `logs/` … 実行ログ(gitには含めない)

## データ形式

`docs/data/YYYY-MM-DD.json.gz` を gzip 展開すると:

```json
{"date":"2026-08-26","generated":"...","bars":{"6594":[["09:00",2590.0,2622.0,2586.0,2602.0,320400], ...]}}
```

1本 = `[時刻, 始値, 高値, 安値, 終値, 出来高]`。1日67本(9:00〜15:25の66本 + 15:30の引け)。

Pythonでの読み込み例:

```python
import gzip, json

with gzip.open("docs/data/2026-08-26.json.gz", "rt", encoding="utf-8") as f:
    day = json.load(f)

bars = day["bars"]["6594"]          # ニデックの5分足
close = bars[-1][4]                 # 終値
volume = sum(b[5] for b in bars)    # 出来高合計
```

## TOPIX定期入替(2026年10月)の推計

サイトの「入替推計」タブ。JPX総研「TOPIX算出要領」の定義どおりに、初回の定期入替で
**除外される銘柄 / 新規採用される銘柄**を推計する。

```
py fetch_rebalance.py     # 生データ取得(株探の日足・銘柄情報・大株主) -> cache/  ※再開可能
py build_rebalance.py     # 集計 -> docs/data/rebalance.json
```

### 日程(算出要領に明記されている確定事項)

| | 日付 | 根拠 |
|---|---|---|
| 定期入替基準日 | 2026-08-31 (8月最終営業日) | この日の大引けで全データ確定 |
| 選定結果の公表 | 2026-10-07 (10月第5営業日) | JPXサイト |
| 入替実施 | 2026-10-30 (10月最終営業日) | |
| 移行措置の完了 | 2028-07-31 | ×0.875から四半期ごと8段階で×0 |

### 選定基準

| 指標 | 追加基準 | 継続基準 |
|---|---|---|
| 年間売買代金回転率 | 0.2以上 | 0.14以上 |
| 浮動株時価総額の累積比率 | 上位96%以内 | 上位97%以内 |

- **浮動株時価総額** … 基準日が属する月(2026年8月)の**日次平均**。単日の終値ではない
- **年間売買代金回転率** … 2025年9月〜2026年8月の月次回転率の合計。
  月次 = (日次売買代金の中央値 × 営業日数) ÷ 月末最終営業日の浮動株時価総額

### データの作り方

- **現構成銘柄の浮動株時価総額**(精度高): JPX公開の
  [topixweight_j.csv](https://www.jpx.co.jp/automation/markets/indices/topix/files/topixweight_j.csv)
  のウエイトから浮動株株数を逆算し、JPX資料の公表値(浮動株時価総額の合計691兆円 @ TOPIX 3,644.58pt)
  で絶対額に換算。**検算**: 株探の日足から出した2026年3月のTOPIX月間平均が3,644.58ptとJPX公表値に一致した
- **足切り値**: JPX公表の「累積97%以内の最小浮動株時価総額 約360億円(2026年3月末)」を
  8月の指数水準に換算(約404億円)。96%側は自前計算の96%/97%比で換算
- **売買代金**: 株探の日足レスポンス**7列目が売買代金(百万円)**。JPXの定義式にそのまま使える
- **浮動株比率**(採用側のみ・精度低): JPXしか持っていない非公開データなので、
  株探の大株主上位10名から親会社・事業会社・創業家・自己株式・持株会を非浮動として差し引いて推計

### 落とし穴

1. **基準日は8月31日であって「今日」ではない**。9月以降の株価・出来高は選定結果を1ミリも動かさない
2. **単日の終値時価総額ではない**。浮動株時価総額は8月の日次平均、回転率は直近12か月
3. **時価総額ではなく浮動株時価総額**。政策保有株が多い銘柄は素の時価総額よりかなり小さく評価される
4. 採用候補の母集団は `symbols.csv`(非TOPIX・時価総額350億円超)。ここに無い銘柄は拾えない
5. 除外銘柄は10/30に即座に指数から消えるわけではない(8段階のウエイト逓減)

## 仕様上の注意

- 株探の5分足エンドポイント(`stock/read?c=<code>&m=5&k=1`)は**直近5営業日分**を返す。
  そのため取得に失敗した日やPCが落ちていた日があっても、**4営業日以内に実行すれば自動で埋め戻る**
  (既存ファイルにマージする実装になっている)。
- `m` が足種。1=日足 / 2=週足 / 3=月足 / 4=1分足 / 5=5分足 / 6=年足。`k` は効かない。
- レスポンス1行目の2列目は**市場コード**(0=指数, 1=東証, 3=名証, 6=福証, 8=札証)。
  「0か1のみ有効」と判定すると名証・福証・札証の銘柄が丸ごと欠落するので注意。
  株価の除数は指数のみ100、それ以外は全市場10。
- 2763(エフティグループ)と3271(THEグローバル社)は上場廃止済みでデータが返らない。
